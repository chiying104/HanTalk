📱 iPhone 上傳 GitHub 教學

不要直接上傳 ZIP。必須先在「檔案」App 解壓縮。
  1. 下載 ZIP 後，到 iPhone「檔案」App，點一下 ZIP 解壓縮。
  2. 打開解壓後的資料夾，確認第一層直接看到：index.html、manifest.webmanifest、sw.js、icons 資料夾。
  3. 進入 GitHub 的 HanTalk Repository，先刪除舊版檔案，避免舊路徑衝突。
  4. 按 Add file → Upload files，選取解壓後的檔案。資料夾必須保持原本結構。
  5. 最外層必須直接看到 index.html，不能再包在 HanTalk_v4 資料夾裡。
  6. 按 Commit changes 完成上傳。
  7. 到 Settings → Pages，確認來源為 Deploy from a branch／main／root。
  8. 等待約 1–3 分鐘，再開啟網站。

⚠️ 上傳時最常見錯誤

  • 404：index.html 不在最外層，或 Pages 尚未部署完成。
  • 只顯示標題：舊快取或檔案沒有完整上傳。
  • 圖示失效：icons 資料夾被拆開，或 icon.svg 放錯層級。
  • 仍看到舊版：Safari 長按重新整理，或到設定清除該網站資料。
  • 發音沒聲音：關閉靜音模式、提高音量，再重新點一次。
