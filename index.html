📲 加入手機主畫面

iPhone（Safari）
  1. 用 Safari 開啟 HanTalk。
  2. 點下方「分享」圖示。
  3. 選「加入主畫面」。
  4. 點右上角「新增」。
Android（Chrome）
  1. 用 Chrome 開啟 HanTalk。
  2. 點右上角「⋮」。
  3. 選「加入主畫面」或「安裝應用程式」。
  4. 確認安裝。
